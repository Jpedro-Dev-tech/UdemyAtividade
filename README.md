
# ☕ Fundamentos de Java

Repositório dedicado aos meus estudos e práticas de **Java**, acompanhando os conteúdos do curso realizado na **Udemy**.

O objetivo é revisar conceitos fundamentais da linguagem, desenvolver o raciocínio lógico e fortalecer minha base de programação por meio de exercícios práticos.

## 📚 Conteúdos estudados

- [x] Entrada de dados (`Scanner`)
- [x] Saída de dados (`System.out.print` e `System.out.println`)
- [x] Estruturas condicionais (`if`, `else` e `else if`)
- [x] Funções e métodos
- [x] Funções matemáticas (`Math`)
- [x] Operadores lógicos (`&&`, `||` e `!`)
- [x] Operadores aritméticos e relacionais
- [x] Estrutura condicional `switch case`

## 🛠️ Tecnologias e ferramentas

- **Java** — Linguagem de programação
- **IntelliJ IDEA** — Ambiente de desenvolvimento
- **Git e GitHub** — Versionamento e armazenamento dos exercícios

## 🎯 Objetivos

- Consolidar os fundamentos da linguagem Java.
- Praticar lógica de programação.
- Desenvolver a capacidade de resolver problemas.
- Aprimorar a organização e a escrita de código.
- Construir uma base sólida para avançar em Java e Spring Boot.

## 📈 Evolução dos estudos

Este repositório será atualizado conforme novos conteúdos forem estudados e novos exercícios forem desenvolvidos.

Cada implementação representa uma oportunidade de praticar, identificar erros e aprimorar minha compreensão sobre programação.
